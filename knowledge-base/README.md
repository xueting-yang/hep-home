# Knowledge Base

个人研究知识库 - 不是资料仓库，而是"能逼你产出判断、复盘和决策"的系统。

## 目标

服务四类输出：
1. **快速进入新课题** - 快速判断问题价值和方法创新点
2. **深化基础理解** - 打透核心概念，形成可讲授的理解
3. **沉淀个人研究主线** - 记录决策、失败和方法论
4. **形成个人方法库** - 建立可复用的研究操作系统

## 结构

### 00_dashboard - 仪表盘
- `yearly_strategy.md` - 年度研究策略
- `current_focus.md` - 当前重点
- `weekly_review.md` - 每周复盘

### 01_frontier_map - 前沿地图
对前沿问题的结构化地图，每个主题包含：
- 核心物理问题
- 关键实验 observable
- 主要实验进展
- 当前瓶颈
- 未来 2-5 年展望

### 02_core_concepts - 核心概念库
按"经常要解释给别人听"的单位整理，统一结构：
- 一句话定义
- 物理图像
- 数学表达
- 在实验里怎样出现
- 常见误解
- 与相近概念的区别
- 具体例子
- 我的理解盲点

### 03_papers - 论文库
按年份和主题索引组织，使用统一模板深度拆解

### 04_research_line - 个人研究主线库
每个项目的完整 dossier，包含：
- 项目背景和物理动机
- 分析策略和关键决策
- Decision Log - 记录为什么这样选择
- Failure Log - 记录失败尝试和排查过程

### 05_toolbox - 工具箱
不是堆命令，而是整理"什么时候该用什么"
- 分析工具（RooFit, sPlot, unfolding...）
- 软件工具（git, workflow, debugging...）
- 协作工具（如何写 issue, note, slides...）

### 06_feynman_lab - 费曼讲解实验室
每个主题写 3 个版本：
- 90 秒版 - 给同领域同学讲
- 5 分钟版 - 给组会听众讲
- 15 分钟版 - 给非本子方向但懂高能的人讲

### 07_agents - 思维角色
不同视角的思维模式：
- Experimental Analyst - 关注可行性和系统误差
- Theory Interpreter - 关注物理意义和理论预言
- Statistics Reviewer - 关注统计方法和假设
- Skeptical Reviewer - 专门挑漏洞找盲点

### 08_templates - 模板库
统一的结构化模板，确保知识库不失控

### 09_decisions - 决策记录
重要决策的完整记录，包含背景、推理、结果和反思

## 使用原则

1. **最小单元是"问题"，不是"主题"**
2. **记录判断、决策和失败，不只是摘抄**
3. **强制用统一模板，否则迟早失控**
4. **每周复盘，持续迭代**
