# Gamma Measurements

## Core Physics Question
How precisely can we measure the CKM angle γ (φ₃) to test the unitarity of the CKM matrix and search for new physics?

## Key Experimental Observables
- B → DK decay rates and asymmetries
- Time-dependent CP asymmetries in B_s → D_s K
- GLW, ADS, GGSZ methods

## Main Experiments
- **LHCb**: Tree-level B → DK decays
- **Belle II**: B factories with clean environment
- **ATLAS/CMS**: B_s → D_s K time-dependent measurements

## Representative Analysis Strategies
- Combine multiple decay modes
- Exploit interference between b→c and b→u transitions
- Model-independent extraction using Dalitz plot analysis

## Current Bottlenecks
- Statistical precision
- Charm strong-phase uncertainties
- Systematic effects from detector asymmetries

## Future 2-5 Years
- LHCb Upgrade II: 10x more data
- Belle II: Full dataset
- Combined world average: δγ < 1°
